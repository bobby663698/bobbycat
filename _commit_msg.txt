feat(ui): scenes sheet — group timelines into named scenes

The scene data layer and its four commands landed in daa82af, but Slint
had no way to reach them. This adds the sheet: one chip per scene with the
active timeline's scene highlighted, click to group, double-click to
rename, hover-x to remove, and an always-offered "ungrouped" chip to take
a timeline back out. Adding a scene also groups the active timeline into
it, so one click yields a usable scene.

- ui/dialogs/scenes.slint: SceneChipData, ScenesSheetData, ScenesDialog
- ui/app.slint: import, export, property, callbacks, dialog instance
- panes/scenes.rs: ScenesPane with Msg/data/update; every edit via
  Studio::apply so undo and dirty-marking stay in one place
- panes/mod.rs, studio.rs, studio/{project_files,keyframes}.rs, lib.rs:
  Msg route, pane field/init, publish, callbacks and the studio.scenes menu row
- locales/*.json: 8 new keys in all 26 locales (English fallback, as the
  scripts.* keys already do)

Local verification: static only. This machine has no MSVC link.exe, so
cargo clippy fails on dependency build scripts. Compile and i18n tests
are left to CI.
